# 會議記錄摘要

## 1. 會議概況
- **日期**：逐字稿未提及
- **參與者**：產品負責人 (Product owner)、產品經理、資料團隊、運維團隊 (Operations team)、研發團隊、法務
- **會議主題**：無人機巡檢平台第二季里程碑與風險清單確認、升級版語音引擎部署計畫驗證

## 2. 執行摘要 (Executive Summary)
本次會議旨在確認無人機巡檢平台第二季之里程碑、風險清單及語音引擎部署計畫。核心決議包括：由資料團隊修正 API 串接延遲問題；運維團隊需確保 Windows GPU 環境部署之可重複性及 CPU 回退機制；針對多語言語音驗證，要求保留台語標記供審核但正式產品須剔除。此外，強調所有對外展示資料必須完成去識別化以符合合規要求。後續將針對展演現場設備、模型部署 Checklist 及教育訓練簡報進行準備。

## 3. 詳細議題與決議 (Discussion & Decisions)
- **議題 1**：API 串接延遲問題
  - *討論重點*：分析延遲主因為影像標註流程尚未完全自動化。
  - *最終決議*：由資料團隊於下週二完成修正。

- **議題 2**：展演活動現場佈署
  - *討論重點*：為避免測試當天重工，且在網路不穩時需能切換至離線模式。
  - *最終決議*：提前確認電力、網路、備援電池與收音設備。

- **議題 3**：模型部署與驗證 (Windows GPU 環境)
  - *討論重點*：確保 GPU 部署在不同環境具備可重複性；若 torch 無 CUDA 支援，執行器必須能回退 (fallback) 至 CPU 運作而非導致系統崩潰。
  - *最終決議*：確認 Docker 映像版本、模型快取目錄與 health check 參數保持一致。

- **議題 4**：多語言語音驗證 (中/英/台語)
  - *討論重點*：驗證混合語音轉錄之穩定性。Demo 錄音將交替使用中文更新、英文待辦事項與台語現場回饋，以壓力測試轉錄路徑。
  - *最終決議*：測試產物需保留台語段落標記供審核，但正式產品輸出不得出現測試標記。

- **議題 5**：資料安全性與合規
  - *討論重點*：對外展示之資料必須符合去識別化規範。
  - *最終決議*：包含試錄音檔、畫面截圖與下載文件名稱均須執行去識別化處理。
