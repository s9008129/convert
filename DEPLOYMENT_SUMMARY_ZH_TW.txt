🚀 快速啟動步驟
═══════════════════════════════════════════════════════════════════

【方案 1：使用 Batch 腳本（推薦初學者）】

1. 打開檔案總管
2. 進入 convert\scripts 資料夾
3. 雙擊 start.bat
4. 等待「MeetingScribe 已就緒！」訊息
5. 打開瀏覽器 → http://localhost:9527

【方案 2：使用 PowerShell（推薦進階用戶）】

# 開啟 PowerShell（以系統管理員身份）
cd C:\Users\YourName\Documents\convert

# 首次：建構映像
.\scripts\deploy.ps1 build

# 啟動服務
.\scripts\deploy.ps1 up

# 檢查狀態
.\scripts\health-check.ps1

# 查看日誌（如有問題）
.\scripts\deploy.ps1 logs

【方案 3：使用 Docker 直接部署（RTX 4090 專用配置）】

cd docker
docker compose -f docker-compose-windows-gpu.yml up -d

💡 重要提示
═══════════════════════════════════════════════════════════════════

✅ 本地模式 vs 雲端模式
   • 本地模式：使用 Ollama + Gemma3（離線，隱私）
   • 雲端模式：使用 Google Gemini API（需設定 API Key）

✅ 性能期望（RTX 4090）
   • 30 分鐘音訊 → 3-5 分鐘轉錄時間
   • 60 分鐘音訊 → 6-10 分鐘轉錄時間
   • CPU 模式約慢 5 倍

✅ Ollama 下載模型說明
   • Gemma3:27b-it-qat 約 16GB
   • 首次下載 15-30 分鐘（取決於網路）
   • 使用命令：ollama pull gemma3:27b-it-qat

✅ 檔案上傳限制
   • 預設上限：200 MB
   • RTX 4090 可支援 500 MB（編輯 .env）
   • 支援格式：MP3, WAV, M4A, MP4, MOV

⚠️ 常見陷阱
═══════════════════════════════════════════════════════════════════

❌ Docker 未啟動 GPU 支援
   → 開啟 Docker Desktop Settings → Resources → GPU → ✅ Enable

❌ Ollama 無法連接
   → 確認 ollama serve 已啟動（另開 PowerShell 視窗）
   → 檢查：Invoke-RestMethod -Uri "http://localhost:11434/api/tags"

❌ nvidia-smi 顯示「驅動未安裝」
   → 下載最新驅動：https://www.nvidia.com/Download/driverDetails.aspx/199537
   → 使用「Custom」安裝 + 「Clean Install」

❌ 服務啟動後無法連接
   → 執行：docker ps 檢查容器狀態
   → 執行：docker logs meetingscribe-app 查看錯誤
   → 重啟：.\scripts\deploy.ps1 restart
