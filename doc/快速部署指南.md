## 開始之前

### ✅ 您需要準備

| 項目 | 說明 | 必要性 |
|------|------|--------|
| **Windows 11 電腦** | 已安裝好的電腦 | 必要 |
| **NVIDIA 顯示卡** | RTX 3060 以上，建議 RTX 4090 | 建議（無 GPU 也可運行，但較慢） |
| **網路連線** | 首次安裝需下載約 10GB 檔案 | 首次必要 |
| **管理員權限** | 安裝軟體時需要 | 必要 |

### ⏱️ 預估時間

- 首次完整安裝：30-60 分鐘（依網路速度）
- 之後每次啟動：1-2 分鐘
- 服務啟動後可立即使用

## 步驟一：安裝必要軟體

### 1.1 安裝 Docker Desktop

Docker 是一個讓程式能在任何電腦上以相同方式運行的工具。

**安裝步驟：**

1. 開啟瀏覽器，前往：https://www.docker.com/products/docker-desktop/

2. 點擊 **「Download for Windows」** 按鈕

3. 下載完成後，雙擊安裝檔案 `Docker Desktop Installer.exe`

4. 安裝過程中：
   - ✅ 勾選 **「Use WSL 2 instead of Hyper-V」**
   - ✅ 勾選 **「Add shortcut to desktop」**
   - 點擊 **「OK」** 繼續

5. 安裝完成後，**重新啟動電腦**

6. 重新開機後，Docker Desktop 會自動啟動
   - 等待右下角系統匣出現 🐋 鯨魚圖示
   - 圖示變成穩定（不再轉動）表示 Docker 已就緒

**驗證安裝成功：**

1. 在桌面按 `Win + R`，輸入 `cmd`，按 Enter
2. 輸入以下指令，按 Enter：
   ```
   docker --version
   ```
3. 如果顯示 `Docker version 2x.x.x` 表示安裝成功

---

### 1.2 安裝 Ollama（本地 AI 模型）

Ollama 是讓您在本機執行 AI 模型的工具，用於處理機敏資料。

**安裝步驟：**

1. 開啟瀏覽器，前往：https://ollama.ai

2. 點擊 **「Download」** 按鈕

3. 選擇 **「Windows」** 版本下載

4. 下載完成後，雙擊安裝檔案，依照提示完成安裝

5. 安裝完成後，Ollama 會自動啟動
   - 您會在系統匣看到 Ollama 圖示 🦙

**下載 AI 模型（Gemma3:12B）：**

1. 在桌面按 `Win + R`，輸入 `cmd`，按 Enter

2. 輸入以下指令，按 Enter：
   ```
   ollama pull gemma3:12b
   ```

3. 等待下載完成（約 5-10 分鐘，依網路速度）
   - 下載過程中會顯示進度條
   - 完成後會顯示 `success`

**驗證安裝成功：**

在命令提示字元輸入：
```
ollama list
```

如果顯示 `gemma3:12b` 表示模型已安裝

---

### 1.3 確認 NVIDIA 顯示卡驅動（有 GPU 的情況）

如果您的電腦有 NVIDIA 顯示卡，請確認驅動程式已安裝：

1. 在桌面按 `Win + R`，輸入 `cmd`，按 Enter

2. 輸入以下指令，按 Enter：
   ```
   nvidia-smi
   ```

3. 如果顯示您的顯示卡資訊（如 RTX 4090），表示驅動已安裝

4. 如果顯示錯誤，請前往 https://www.nvidia.com/drivers 下載最新驅動

## 步驟二：下載專案

### 方法 A：使用 Git（推薦）

1. 開啟命令提示字元（`Win + R` → `cmd` → Enter）

2. 切換到您想放置專案的資料夾，例如桌面：
   ```
   cd %USERPROFILE%\Desktop
   ```

3. 下載專案：
   ```
   git clone https://github.com/s9008129/convert.git
   ```

4. 進入專案資料夾：
   ```
   cd convert
   ```

### 方法 B：直接下載 ZIP

1. 開啟瀏覽器，前往：https://github.com/s9008129/convert

2. 點擊綠色 **「Code」** 按鈕

3. 選擇 **「Download ZIP」**

4. 下載完成後，解壓縮到桌面

5. 將解壓縮後的資料夾重新命名為 `convert`

## 步驟三：設定環境

### 3.1 開啟 PowerShell

1. 在開始選單搜尋 **「PowerShell」**

2. **右鍵點擊** 「Windows PowerShell」

3. 選擇 **「以系統管理員身分執行」**

4. 如果出現權限詢問，點擊 **「是」**

### 3.2 進入專案資料夾

在 PowerShell 中輸入（根據您專案的實際位置調整）：

```powershell
cd $env:USERPROFILE\Desktop\convert
```

### 3.3 設定 Gemini API Key（雲端模式，選用）

如果您想使用雲端模式獲得更高品質的摘要，需要設定 Gemini API Key：

1. 在 PowerShell 中執行：
   ```powershell
   cd scripts
   .\setup-api-key.ps1
   ```

2. 依照畫面指示操作：
   - 前往 https://makersuite.google.com/app/apikey
   - 使用 Google 帳號登入
   - 點擊「Create API Key」
   - 複製產生的 API Key
   - 回到 PowerShell 貼上 API Key

> 💡 **提示**: 如果只使用本地模式處理機敏資料，可以跳過此步驟

## 步驟四：啟動服務

### 4.1 首次建構 Docker 映像

首次使用需要建構 Docker 映像，這會下載所有需要的元件：

1. 確保您在專案根目錄：
   ```powershell
   cd $env:USERPROFILE\Desktop\convert
   ```

2. 執行建構指令：
   ```powershell
   cd scripts
   .\deploy.ps1 build
   ```

3. 等待建構完成
   - ⏱️ 首次建構約需 15-30 分鐘
   - 過程中會下載約 8-10GB 的檔案
   - 完成後會顯示 `[OK] 映像建構完成`

### 4.2 啟動服務

建構完成後，啟動服務：

```powershell
.\deploy.ps1 up
```

等待約 1-2 分鐘，看到以下訊息表示啟動成功：

```
═══════════════════════════════════════════
  🎉 MeetingScribe 已就緒！
═══════════════════════════════════════════
  📍 網址: http://localhost:9527
═══════════════════════════════════════════
```

### 4.3 驗證服務狀態

執行健康檢查：

```powershell
.\health-check.ps1
```

確認所有項目都顯示 ✅ 表示服務正常運作。

## 步驟五：開始使用

### 5.1 開啟網頁介面

1. 開啟瀏覽器（Chrome、Edge 或 Firefox）

2. 在網址列輸入：
   ```
   http://localhost:9527
   ```

3. 您會看到 MeetingScribe 的主畫面

### 5.2 處理會議錄音

1. **選擇處理模式**
   - 🔒 **本地模式**：適合機敏資料，完全離線處理
   - ☁️ **雲端模式**：適合一般會議，品質較高

2. **上傳檔案**
   - 將會議錄音檔案拖放到上傳區域
   - 或點擊上傳區域選擇檔案
   - 支援格式：MP3, MP4, WAV, M4A, MKV 等

3. **自訂會議記錄格式（選用）**
   - 在「自訂 Prompt」欄位輸入您希望的格式
   - 例如：「請列出所有決議事項和負責人」
   - 留空則使用預設格式

4. **等待處理**
   - 畫面會顯示處理進度
   - 60 分鐘的會議約需 5-10 分鐘處理

5. **下載結果**
   - 處理完成後，可直接在網頁上查看結果
   - 點擊「下載 Markdown」儲存會議記錄

## 常見問題

### ❓ Docker Desktop 無法啟動

**症狀**: 右下角沒有鯨魚圖示，或顯示錯誤

**解決方法**:
1. 確認已啟用 Windows 的「虛擬化」功能
   - 重新開機，進入 BIOS
   - 啟用 Intel VT-x 或 AMD-V
2. 確認已安裝 WSL 2
   - 以管理員身分開啟 PowerShell
   - 執行：`wsl --install`
   - 重新開機

---

### ❓ 顯示「GPU 不可用」

**症狀**: 系統自動切換到 CPU 模式

**解決方法**:
1. 確認 NVIDIA 驅動已安裝（執行 `nvidia-smi`）
2. 在 Docker Desktop 設定中啟用 GPU：
   - 開啟 Docker Desktop
   - 點擊右上角 ⚙️ 設定
   - 選擇 Resources → Advanced
   - 確認「Use GPU」已勾選
3. 重新啟動 Docker Desktop

> 💡 即使沒有 GPU，系統仍可使用 CPU 模式運行，只是處理速度較慢

---

### ❓ Ollama 連接失敗

**症狀**: 本地模式無法使用，顯示連接錯誤

**解決方法**:
1. 確認 Ollama 正在運行
   - 檢查系統匣是否有 Ollama 圖示
   - 如果沒有，從開始選單啟動 Ollama
2. 確認模型已下載
   - 開啟命令提示字元
   - 執行：`ollama list`
   - 確認有 `gemma3:12b`
3. 如果模型不存在，執行：`ollama pull gemma3:12b`

---

### ❓ 雲端模式無法使用

**症狀**: 選擇雲端模式後顯示錯誤

**解決方法**:
1. 確認已設定 API Key
   - 執行 `.\scripts\setup-api-key.ps1`
2. 重新啟動服務
   - 執行 `.\scripts\restart-service.ps1`
3. 確認網路連線正常

---

### ❓ 檔案上傳失敗

**症狀**: 上傳時顯示錯誤訊息

**可能原因與解決方法**:
1. **檔案太大**
   - 預設限制 100MB
   - 將大檔案分割或壓縮後再上傳
2. **不支援的格式**
   - 確認是支援的音訊/視訊格式
   - 支援：MP3, MP4, WAV, M4A, MKV, WEBM, OGG, FLAC
3. **檔案名稱有特殊字元**
   - 重新命名檔案，只使用中英文和數字

---

### ❓ 處理速度很慢

**解決方法**:
1. 確認使用 GPU 模式（健康檢查會顯示 GPU 狀態）
2. 關閉其他佔用 GPU 的程式
3. 如果電腦規格較低，可嘗試使用較小的 Whisper 模型
   - 編輯 `.env` 檔案
   - 將 `WHISPER_MODEL=large-v3` 改為 `WHISPER_MODEL=medium`
   - 重新啟動服務

## 日常操作

### 🔄 啟動服務

每次開機後，需要啟動服務：

1. 確認 Docker Desktop 已啟動（右下角有鯨魚圖示）
2. 確認 Ollama 已啟動（右下角有 Ollama 圖示）
3. 開啟 PowerShell，進入專案資料夾
4. 執行：
   ```powershell
   cd scripts
   .\deploy.ps1 up
   ```

### ⏹️ 停止服務

不使用時可以停止服務以釋放資源：

```powershell
.\deploy.ps1 down
```

### 🔁 重新啟動服務

遇到問題時可以重新啟動：

```powershell
.\restart-service.ps1
```

### 🩺 檢查系統狀態

隨時可以檢查系統是否正常：

```powershell
.\health-check.ps1
```

### 📋 查看服務日誌

如果遇到問題，可以查看詳細日誌：

```powershell
.\deploy.ps1 logs
```
