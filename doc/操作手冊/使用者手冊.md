## 1. 系統簡介

政府智慧會議紀錄生成系統是一套**會議錄音轉會議紀錄**的自動化工具。

### 它能做什麼？

- 🎙️ 接收您的會議錄音檔（MP3、MP4、WAV 等常見格式）
- 📝 自動將語音轉為逐字稿
- 📋 由 AI 整理出結構化的會議紀錄（含議題、決議、待辦事項）
- 🗂️ 依**會議類型**套用專屬格式與規則（見下方「會議類型」說明）
- 📄 提供 **Word (DOCX)**、**Markdown** 與**逐字稿 (.txt)** 三種下載

### 使用情境

適合需要快速產出會議紀錄的場合，例如：
- 政府機關例行會議
- 專案進度檢討會
- 跨部門協調會議
- 訪談紀錄整理
- 科室內部科務會議（含決議事項辦理情形彙整表、列管資料）
- 政府採購評選委員會會議（機敏內容，僅限本地處理）

### 會議類型（選擇後自動套用專屬格式）

上傳前，畫面最上方會請您先選擇「會議類型」，系統會依所選類型套用不同的
紀錄格式與規則：

| 會議類型 | 格式重點 | 處理模式 |
|------|------|------|
| 📄 一般會議（預設） | 通用公務紀錄：會議名稱／報告事項／討論事項／主席裁示事項 | 本地或雲端皆可 |
| 🏢 科務會議 | 依科室官方範本：時間地點主持人／歷次列管案件／**決議事項辦理情形彙整表**（誰承辦一目瞭然）／條列式科長指示 | 本地或雲端皆可 |
| 🔒 採購評選會 | 依工程會官方範本（壹、貳、參…）：委員提問一律**匿名**、廠商**具名**、逐項詢答對應、個別評分等機敏數字**絕不寫入紀錄** | **僅限本地**（機敏內容強制保護） |

> 💡 不確定選哪個？選「**一般會議**」最保險，適用於大多數場合。

> 🔒 **重要**：選擇「採購評選會」時，系統會**自動鎖定為本地模式**、雲端
> 選項會變灰無法選取——這是刻意的保護機制，確保機敏錄音內容絕不外傳，
> 即使您誤觸也無法切換到雲端（後端也有第二層防護）。

### 品質把關（您不用操作，系統自動做）

- ✅ **同音錯字自動校正**：轉錄完成後，系統會自動修正同音、近音錯字（只修發音相近的字，嚴防改壞原意）
- ✅ **摘要自動驗證＋補強**：會議紀錄產出前會先自動檢查——內容過薄、混入英文、出現簡體字，都會被攔下來重寫
- ✅ **絕不杜撰**：錄音裡查不到的資訊一律標「（待確認）」，不會亂編人名、單位或日期

## 2. 開始使用前的準備

### 您需要準備的東西

| 項目 | 說明 |
|------|------|
| 📁 會議錄音檔 | MP3、MP4、WAV、M4A 等格式皆可，檔案大小上限**以頁面上顯示的數字為準**（機關正式主機為 500MB） |
| 💻 電腦 | macOS 或 Windows 皆可 |
| 🌐 瀏覽器 | Chrome、Edge、Safari、Firefox 皆可（建議使用最新版本） |

### 支援的錄音格式

MP3、MP4、WAV、M4A、MKV、WebM、OGG、FLAC、AVI、MOV

> 💡 **建議**：錄音品質越清晰，轉出的會議紀錄準確度越高。建議使用桌上型麥克風或會議室收音設備。

## 3. 啟動系統

### 🏢 機關同仁（最常見的情況）

機關正式環境通常**已由系統管理員啟動**，您什麼都不用裝、不用設定，直接打開瀏覽器，在網址列輸入：

```
http://10.97.15.58:9527
```

（或系統管理員提供給您的網址）就可以開始使用了。

### macOS 使用者（自己的電腦）

1. 開啟「終端機」應用程式（可在 Launchpad 搜尋「Terminal」或「終端機」）
2. 輸入以下指令並按下 Enter：
   ```
   cd /Users/hsiaojohnny/dev/convert
   ./start_service.sh
   ```
3. 看到啟動成功訊息後，打開瀏覽器輸入 `http://localhost:9527`

### Windows 使用者（Docker 方式，自己的電腦）

1. 確認已安裝 Docker Desktop 並啟動
2. 開啟「命令提示字元」或「PowerShell」
3. 切換到專案資料夾，執行：
   ```
   cd docker
   docker compose up -d
   ```
4. 打開瀏覽器輸入 `http://localhost:9527`

## 5. 步驟①：選擇會議類型、模式與上傳錄音

進入畫面後，最上方會先看到一張**整寬的「選擇會議類型」卡片**，下方才是左右並排的模式與上傳卡片。

### 最上方：選擇會議類型

畫面會列出目前系統支援的所有會議類型卡片（清單由系統自動提供，管理員新增
類型時卡片也會自動出現，不需要更新網頁）。點選您要使用的類型：

- 每張卡片顯示**類型名稱**與**簡短說明**
- 涉及機敏內容的類型（例如「採購評選會」）卡片上會有橘色「**機敏・僅限本地**」
  標籤，選取後畫面上方會出現提示文字說明原因
- 選定的類型會維持選取狀態，直到您重新整理頁面或按「重新開始」

> 💡 會議類型只影響**紀錄的格式與撰寫規則**，不影響上傳與轉錄流程；
> 選錯了也沒關係，任務開始前都可以重新選擇。

### 左卡：選擇處理模式

| | 🛡️ 方案 A：本地模式（預設已選好） | ☁️ 方案 B：雲端模式 |
|---|---|---|
| 特色 | 完全離線處理、資料不外傳 | 高品質摘要、處理速度較快 |
| 適合 | **機敏資料**、不確定時選這個 | 非機敏資料 |

- 每張卡片底部會**動態顯示目前實際使用的 AI 模型名稱**，例如「使用模型：XXX（已就緒）」——這是系統自動帶入的，管理員換了模型也會自動同步，不用擔心資訊過時
- 如果系統尚未設定雲端 API Key，**雲端模式卡片會變灰、無法點選**，並顯示黃色警告提示——這是正常的保護機制，表示這台主機只提供本地模式
- 若您選擇的**會議類型涉及機敏內容**（如「採購評選會」），雲端模式卡片也會變灰並自動鎖定為本地模式，即使雲端 API Key 已設定也無法選取
- 用滑鼠點選，或用鍵盤 **Enter／空白鍵** 都可以切換

> 💡 如果不確定選哪個，用預設的「**本地模式**」就對了——所有處理都在主機上完成，錄音完全不會離開機關。

### 右卡：上傳會議錄音

- 一個大大的虛線框，兩種方式擇一：
  - **方法一**：直接把錄音檔**拖曳**進虛線框
  - **方法二**：**點擊**虛線框，從檔案總管選取檔案
- 選好檔案後**系統會自動開始處理**，不需要再按任何「送出」按鈕
- 支援格式與檔案大小上限都寫在框內，**以頁面顯示為準**

> 🔒 任務開始後，模式卡會**鎖定**並顯示「處理中，模式已鎖定」，避免中途誤觸切換——這是刻意設計，處理完成後就會解鎖。

## 7. 步驟③：下載會議紀錄

處理完成後，畫面會出現**綠色打勾**與「處理完成」字樣，以及以下按鈕：

| 按鈕 | 樣式 | 功能 |
|------|------|------|
| 📄 **下載會議紀錄 (Word)** | 藍色主按鈕 | ⭐ **最推薦！** 下載 .docx，用 Word 開啟即可直接編輯、列印、簽核 |
| 📎 **下載列管資料 (Word)** | 藍色主按鈕 | 只有選擇「**科務會議**」類型才會出現，下載另一份獨立的 .docx（決議事項辦理情形彙整表，格式與會議紀錄本文一致，方便單獨追蹤列管） |
| ⬇️ 下載 Markdown | 白底次按鈕 | 下載 .md 純文字格式，適合進一步編輯或貼到其他系統 |
| 📝 下載逐字稿 | 白底次按鈕 | 下載 .txt 完整逐字稿，方便**核對原話** |
| 🔄 重新開始 | 文字按鈕 | 回到第一步，處理下一個錄音檔 |

> 💡 「下載列管資料」按鈕**只會在「科務會議」類型才出現**；其他會議類型（一般會議、採購評選會）不會顯示這顆按鈕，屬於正常現象。

### 下載 Word 檔案（推薦做法）

1. 點擊藍色的「**下載會議紀錄 (Word)**」按鈕
2. 瀏覽器會自動下載一個 `.docx` 檔案
3. 用 **Microsoft Word**（Office 2024 / Microsoft 365）開啟即可

### Word 檔案的特色

- ✅ **A4 標準頁面**，可直接列印
- ✅ **中文字型**已設定好（標題：微軟正黑體、內文：新細明體）
- ✅ **表格框線完整**，不會出現看不到框線的問題
- ✅ **公文層次分明**（v4.3.2 起）：「一、二、三」章節標題自動**加粗放大**（深藍色 15pt）、「會議名稱：」「案由：」「決議：」等欄位名稱自動**加粗**——Word 一打開就有公文的層次感，幾乎不用再調格式
- ✅ 相容 **Office 2024** 與 **Microsoft 365**

### 如果出現錯誤畫面

偶爾處理會失敗，畫面會顯示**紅色警告**與白話的錯誤說明。請按「**重新開始**」再試一次；若持續失敗，請把畫面上的錯誤訊息記下來（或截圖），聯絡系統管理員。

## 8. 會議紀錄內容說明

> ⚠️ 以下結構為**「一般會議」類型**的預設格式。若您選擇「科務會議」或
> 「採購評選會」，紀錄結構會改依該類型的官方範本呈現（詳見下方「不同會議
> 類型的紀錄結構」），但「絕不杜撰」「（待確認）」等品質把關原則完全相同。

系統產出的會議紀錄（一般會議類型）包含以下結構：

### 📌 1. 會議概況
- **第一行一定是「會議名稱：」**，接著是日期、參與者、案由等基本欄位

### 📌 2. 執行摘要
- 快速說明會議重點結論

### 📌 3. 詳細議題與決議
- 每個討論議題的重點與最終決議

### 📌 4. 待辦事項（表格）
| 待辦事項 | 負責人 | 期限 |
|----------|--------|------|
| 例：準備報告 | 張三 | 3 月 15 日 |

### 📌 5. 其他備註
- 下次會議時間、特殊注意事項等

> 💡 **三個您該知道的貼心設計**：
> 1. **「（待確認）」**：AI 從錄音中查不到的資訊會標示「（待確認）」，**絕不杜撰**——看到它，補上正確資訊即可。
> 2. **逐字稿可另外下載**：想核對 AI 整理得對不對？下載 .txt 逐字稿對照原話最快。
> 3. **失敗不偽裝成功**：萬一 AI 摘要生成失敗，檔案仍然會產出（保留完整逐字稿），並在開頭放上**明顯的警告橫幅**提醒您這份沒有摘要——不會假裝一切正常。

### 🗂️ 不同會議類型的紀錄結構

**科務會議**（依科室官方範本）：
- 時間、地點、主持人、出席人員（如後附簽到表）
- 歷次科務會議決議事項繼續列管案件（沒討論到就標「（待確認）」，不會亂填「無」）
- **決議事項辦理情形彙整表**：每項交辦事項一列，清楚寫出承辦股或承辦同仁
- 科長轉知事項、科長指示及提醒事項（依主題分層條列）
- 上述彙整表會**另外產出一份「列管資料」Word 檔**，方便單獨列印追蹤（見第 7 節）

**採購評選會**（依工程會官方範本「壹、貳、參…」編號）：
- 委員會組成、出席／請假委員、列席人員、評選方式、投標廠商家數及名稱
- 廠商簡報及詢答事項：**「委員提問：」與「廠商答詢：」逐項成對記載**
- 委員提問一律**匿名**（不寫委員姓名）；廠商發言**具名**（照逐字稿公司名稱）
- 個別委員評分、底價等法定機敏數字，一律改記「（機敏資訊，不列入紀錄）」，
  不會出現在紀錄中；彙整後的評選結果（優勝序位、決議）仍會完整記載

## 9. 常見問題與解答

### Q：上傳後一直在跑，是不是當掉了？

**A**：不用擔心！長時間的錄音（例如 1 小時以上）確實需要較多處理時間。畫面上的階段文字與百分比會持續更新，只要有在動就是正常的。也可以先做其他事，完成後畫面會自動切換。

---

### Q：選錯會議類型了怎麼辦？上傳後還能改嗎？

**A**：只要**任務還沒開始上傳**，都可以隨時重新點選正確的會議類型卡片。
一旦檔案已送出開始處理，該次任務就會依上傳當下選擇的類型處理到底；
如果做錯了，請等這次處理完成（或按「重新開始」），再重新上傳一次並選對類型。

---

### Q：為什麼選「採購評選會」之後，雲端模式就不能選了？

**A**：這是**刻意設計的保護機制**。採購評選會錄音通常涉及委員評分、底價等
依法應保密的機敏內容，系統會強制鎖定為本地模式（畫面上雲端卡片會變灰），
確保錄音檔與內容完全不離開主機、不會傳到外部雲端服務。這項保護前後端都有
把關，無法透過操作繞過。

---

### Q：「下載列管資料」按鈕怎麼不見了？

**A**：這顆按鈕**只在選擇「科務會議」類型時才會出現**。若您這次選的是
「一般會議」或「採購評選會」，該類型沒有列管資料附件，按鈕不會顯示，
屬於正常現象。

---

### Q：為什麼雲端模式的卡片是灰色的、不能選？

**A**：代表這台主機**尚未設定雲端 API Key**，只提供本地模式。這是正常的保護機制（畫面上也會有黃色警告說明）。若機關需要開通雲端模式，請洽系統管理員。

---

### Q：為什麼狀態列的 GPU 有時顯示「使用中」？

**A**：代表 GPU 正在替其他同仁的任務工作中，**不是故障**。您仍然可以上傳檔案，系統會自動排隊，輪到您時就會開始處理。

---

### Q：我可以同時上傳多個檔案嗎？

**A**：系統採用排隊機制，一次處理一個檔案。您可以陸續上傳，畫面會清楚顯示**目前排隊件數**與**您的順位**，依序處理。

---

### Q：怎麼把會議紀錄的文字貼到其他文件？

**A**：請先下載檔案再複製：下載 **Word** 檔開啟後直接複製最方便；若您習慣純文字，可下載 **Markdown**。（畫面上沒有「一鍵複製」按鈕，以下載檔案為主。）

---

### Q：Word 檔案在我的電腦上打開格式不對？

**A**：請確認您使用的是 **Microsoft Word**（Office 2024 或 Microsoft 365）。如果使用 LibreOffice 或 WPS Office，部分字型可能會自動替換，但內容不受影響。

---

### Q：會議紀錄的內容不夠準確怎麼辦？

**A**：會議紀錄的品質主要取決於錄音品質。建議：
- 使用指向性麥克風或桌上型麥克風
- 避免在嘈雜環境錄音
- 講話時避免多人同時發言

另外兩個小技巧：
- 下載**逐字稿 (.txt)** 對照原話，快速找出需要修正的地方
- 機關常用的專有名詞（單位名、計畫名、人名），可請系統管理員加入詞彙表，轉錄會越來越準

---

### Q：我的錄音檔太大，超過上限怎麼辦？

**A**：檔案大小上限**以上傳框內顯示的數字為準**（機關正式主機為 500MB）。若超過上限，建議用音訊壓縮工具將檔案轉為 MP3 格式（128kbps 即可），通常可以大幅縮小檔案。

---

### Q：處理過程中可以關閉瀏覽器嗎？

**A**：可以。系統會在背景繼續處理。再次開啟系統網址後，如果任務已完成，您可以重新查看結果。

---

### Q：本地模式和雲端模式有什麼差別？哪個內容比較豐富？

| | 🛡️ 本地模式 | ☁️ 雲端模式 |
|---|---------|---------|
| 🔒 隱私 | 所有資料留在主機上，完全離線 | 逐字稿會傳到 Google 雲端處理 |
| 📶 網路 | 不需要網路 | 需要網路連線 |
| 🎯 品質 | 良好 | 高品質摘要 |
| ⏱️ 速度 | 取決於主機效能 | 通常較快 |
| 適合 | **機敏資料** | 非機敏資料 |

**內容豐富度**：v4.3.3 起，雲端模式改用與本地模式相同的「**分段萃取**」方法——長會議會先分段仔細整理、再彙整成完整紀錄，所以**長會議的雲端紀錄豐富度已大幅改善**，不會再出現「開了兩小時的會、紀錄只有薄薄一頁」的情況。
