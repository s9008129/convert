## 🛠️ 解決方案

### 方案一：統一環境管理（🔴 Critical）

#### 問題本質
目前專案同時存在 `venv/` 和使用 conda `meetingscribe` 環境，導致：
- `start_service.sh` 可能使用錯誤的 Python
- 依賴安裝位置不一致
- av/PyAV 在 pip 環境難以編譯

#### 解決方案：統一使用 `uv` 進行依賴管理

**為什麼選擇 uv？**
- **速度**：比 pip 快 10-100 倍（Rust 實現）
- **鎖定檔**：`uv.lock` 確保跨環境一致性
- **替代多工具**：取代 pip, pip-tools, pipx, poetry
- **Context7 資料來源**：`/astral-sh/uv` (Benchmark Score: 87.2)

#### 實施步驟

```bash
# 1. 安裝 uv（全域）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. 初始化專案
cd /Users/hsiaojohnny/dev/convert
uv init --name meetingscribe

# 3. 移轉現有依賴
uv add -r requirements.txt

# 4. 鎖定依賴
uv lock

# 5. 同步環境
uv sync
```

#### 配置範例 (pyproject.toml)

```toml
[project]
name = "meetingscribe"
version = "3.5.5"

    "fastapi>=0.109.2",
    "uvicorn[standard]>=0.27.1",
    "faster-whisper>=1.2.1",
    "loguru>=0.7.2",
    # ...其他依賴
]

[project.optional-dependencies]
dev = ["pytest>=7.4.0", "pytest-asyncio>=0.21.0"]
macos = ["mlx-whisper>=0.4.0"]  # macOS 專用

[tool.uv]
# 使用 conda 安裝系統依賴
package = true
```

#### 預期效果
- ✅ 統一的虛擬環境（`.venv/`）
- ✅ 依賴版本鎖定（`uv.lock`）
- ✅ 跨平台可重現的環境

### 方案二：修復 PyAV 依賴問題（🔴 Critical）

#### 問題本質
PyAV 是 FFmpeg 的 Python 綁定，需要系統級 FFmpeg 庫：
- pip 安裝 `av` 需要編譯，macOS 上經常失敗
- conda-forge 的 `av` 包含預編譯二進制
- 兩個環境的 av 不互通

#### 解決方案：混合依賴策略

**步驟 1：使用 conda-forge 安裝系統依賴**
```bash
# 建立乾淨的 conda 環境
conda create -n meetingscribe python=3.10 -y
conda activate meetingscribe

# 安裝需要系統依賴的套件
conda install -c conda-forge ffmpeg av -y
```

**步驟 2：使用 pip/uv 安裝純 Python 依賴**
```bash
# 在 conda 環境中使用 pip
pip install faster-whisper loguru fastapi uvicorn
```

**步驟 3：建立啟動驗證腳本**
```python
# scripts/verify_env.py
"""環境驗證腳本 - 啟動前執行"""

import sys

def verify_dependencies():
    """驗證所有關鍵依賴"""
    errors = []
    
    # 檢查 av (PyAV)
    try:
        import av
        print(f"✅ av (PyAV) v{av.__version__}")
    except ImportError as e:
        errors.append(f"❌ av: {e}")
    
    # 檢查 faster-whisper
    try:
        from faster_whisper import WhisperModel
        print("✅ faster-whisper")
    except ImportError as e:
        errors.append(f"❌ faster-whisper: {e}")
    
    # 檢查 mlx-whisper（macOS 可選）
    try:
        import mlx_whisper
        print("✅ mlx-whisper (MPS 加速可用)")
    except ImportError:
        print("⚠️ mlx-whisper 未安裝（將使用 faster-whisper）")
    
    if errors:
        print("\n🚨 環境驗證失敗：")
        for error in errors:
            print(f"  {error}")
        sys.exit(1)
    
    print("\n✅ 環境驗證通過")

if __name__ == "__main__":
    verify_dependencies()
```

**Context7 資料來源**
- `/delgan/loguru` (Benchmark Score: 94.2 - 最高分)
- `/hynek/structlog` (Benchmark Score: 91.1)

#### 新日誌系統設計

```python
# backend/core/logger.py
"""
MeetingScribe 結構化日誌系統 v2.0

特性：
- 控制台彩色輸出（開發模式）
- JSON 結構化檔案日誌（生產模式）
- 自動日誌輪轉（每日/每 100MB）
- 任務追蹤 ID
- 錯誤堆疊追蹤
"""

import sys
import os
from datetime import datetime
from pathlib import Path
from loguru import logger
from backend.core.config import settings


def setup_logger():
    """設定日誌系統"""
    # 移除預設處理器
    logger.remove()
    
    # 確保日誌目錄存在
    log_dir = Path(settings.DATA_DIR) / "logs"
    log_dir.mkdir(parents=True, exist_ok=True)
    
    # 1. 控制台輸出（彩色，人類可讀）
    logger.add(
        sys.stdout,
        format="<green>{time:YYYY-MM-DD HH:mm:ss}</green> | "
               "<level>{level: <8}</level> | "
               "<cyan>{name}</cyan>:<cyan>{function}</cyan>:<cyan>{line}</cyan> - "
               "<level>{message}</level>",
        level=settings.LOG_LEVEL,
        colorize=True,
        backtrace=True,
        diagnose=True,
    )
    
    # 2. 檔案日誌 - 所有級別（JSON 格式，用於分析）
    logger.add(
        log_dir / "app_{time:YYYY-MM-DD}.log",
        format="{time:YYYY-MM-DD HH:mm:ss.SSS} | {level: <8} | "
               "{name}:{function}:{line} | {message}",
        level="DEBUG",
        rotation="00:00",      # 每天午夜輪轉
        retention="30 days",   # 保留 30 天
        compression="zip",     # 壓縮舊日誌
        encoding="utf-8",
    )
    
    # 3. 錯誤日誌（僅 ERROR 和 CRITICAL，JSON 格式）
    logger.add(
        log_dir / "error_{time:YYYY-MM-DD}.log",
        format="{time:YYYY-MM-DD HH:mm:ss.SSS} | {level: <8} | "
               "{name}:{function}:{line} | {message}",
        level="ERROR",
        rotation="100 MB",
        retention="90 days",
        compression="zip",
        encoding="utf-8",
        backtrace=True,        # 包含完整堆疊
        diagnose=True,         # 包含變數值
    )
    
    # 4. JSON 結構化日誌（用於日誌聚合系統）
    logger.add(
        log_dir / "structured_{time:YYYY-MM-DD}.jsonl",
        serialize=True,        # JSON 格式
        level="INFO",
        rotation="100 MB",
        retention="14 days",
        compression="zip",
    )
    
    return logger


def get_task_logger(task_id: str):
    """取得帶有任務 ID 的日誌器"""
    return logger.bind(task_id=task_id)


# 初始化日誌
log = setup_logger()
```

#### 使用範例

```python
from backend.core.logger import log, get_task_logger

# 一般日誌
log.info("服務啟動")

# 帶任務 ID 的日誌
task_log = get_task_logger("abc123")
task_log.info("開始處理任務")
task_log.error("任務失敗", exc_info=True)

# 結構化資料
log.info("轉錄完成", 
         task_id="abc123",
         duration=45.6,
         audio_length=180.0,
         backend="mlx")
```

- ✅ 控制台即時彩色輸出

- ✅ JSON 結構化日誌（便於分析）
- ✅ 錯誤日誌獨立存儲
- ✅ 自動壓縮和清理

- `config.yaml` - 通用配置
- `config.macos.yaml` - macOS 配置
- `docker/` - Docker 配置

### 方案五：啟動驗證機制（🟡 Medium）

#### 解決方案：啟動前完整環境檢查

```python
# scripts/startup_check.py
"""
啟動驗證腳本
在服務啟動前執行完整環境檢查
"""

import sys
import subprocess
from pathlib import Path


def check_python_version():
    """檢查 Python 版本"""
    version = sys.version_info
    if version < (3, 10):
        return False, f"Python {version.major}.{version.minor} 不支援，需要 3.10+"
    return True, f"Python {version.major}.{version.minor}.{version.micro}"


def check_ffmpeg():
    """檢查 FFmpeg 是否安裝"""
    try:
        result = subprocess.run(
            ["ffmpeg", "-version"], 
            capture_output=True, 
            text=True
        )
        version = result.stdout.split('\n')[0]
        return True, version
    except FileNotFoundError:
        return False, "FFmpeg 未安裝"


def check_critical_modules():
    """檢查關鍵模組"""
    modules = {
        "av": "PyAV (音訊處理)",
        "faster_whisper": "Faster-Whisper (語音轉錄)",
        "fastapi": "FastAPI (Web 框架)",
        "loguru": "Loguru (日誌系統)",
    }
    
    results = []
    for module, description in modules.items():
        try:
            __import__(module)
            results.append((True, f"{description} ✅"))
        except ImportError as e:
            results.append((False, f"{description} ❌: {e}"))
    
    return results


def run_checks():
    """執行所有檢查"""
    print("=" * 60)
    print("🔍 MeetingScribe 環境檢查")
    print("=" * 60)
    
    all_passed = True
    
    # Python 版本
    ok, msg = check_python_version()
    print(f"\n📌 Python: {msg}")
    all_passed &= ok
    
    # FFmpeg
    ok, msg = check_ffmpeg()
    print(f"📌 FFmpeg: {msg}")
    all_passed &= ok
    
    # 關鍵模組
    print("\n📦 依賴檢查:")
    for ok, msg in check_critical_modules():
        print(f"   {msg}")
        all_passed &= ok
    
    print("\n" + "=" * 60)
    if all_passed:
        print("✅ 所有檢查通過，可以啟動服務")
    else:
        print("❌ 環境檢查失敗，請修復上述問題")
        sys.exit(1)


if __name__ == "__main__":
    run_checks()
```
