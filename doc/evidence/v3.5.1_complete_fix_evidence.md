## 🐛 問題1：MLX-Whisper 404 錯誤

### 錯誤現象

用戶在 macOS 上啟動服務後，上傳音訊檔案時出現：

```
處理失敗
404 Client Error. (Request ID: Root=1-6933b83b-52272ec13f547e8629323b4e;300a915f-7a8c-4661-9886-f875e41bd622) 
Repository Not Found for url: https://huggingface.co/api/models/medium/revision/main. 
Please make sure you specified the correct `repo_id` and `repo_type`. 
If you are trying to access a private or gated repo, make sure you are authenticated.
```

### 根本原因分析

透過 CodeReviewerAndRefactor Agent 深度分析，發現：

1. **配置結構不一致**：
   - 程式碼讀取：`whisper.mlx.model`
   - 配置檔只有：`whisper.model`
   
2. **回退到錯誤預設值**：
   - 當 `whisper.mlx.model` 不存在時
   - 直接回退到 `settings.WHISPER_MODEL = "medium"`
   - MLX-Whisper 嘗試從 HuggingFace 下載 `medium/revision/main`
   - 導致 404 錯誤

3. **配置路徑格式錯誤**：
   - 正確格式：`mlx-community/whisper-large-v3-turbo`（完整 HuggingFace 路徑）
   - 錯誤格式：`medium`（簡短名稱，會被誤解）

### 修復方案

#### 1. config.mac.yaml

```yaml
# 修復前
whisper:
  backend: mlx-whisper
  model: mlx-community/whisper-large-v3-turbo  # ❌ 錯誤層級
  device: mps

# 修復後
whisper:
  backend: mlx-whisper
  
  # MLX-Whisper 設定
  mlx:
    model: mlx-community/whisper-large-v3-turbo  # ✅ 正確層級
    device: mps
    fp16: true
    language: zh
  
  # 通用設定（用於 Faster-Whisper 降級）
  device: mps
  compute_type: float16
```

#### 2. backend/services/transcription.py

```python
# 修復前
model_name = get_config_value(config, 'whisper.mlx.model', settings.WHISPER_MODEL)

# 修復後 - 實作3層回退機制
model_name = get_config_value(config, 'whisper.mlx.model', None)

# 若未設定 mlx.model，回退到 whisper.model 或預設值
if not model_name:
    model_name = get_config_value(config, 'whisper.model', 'mlx-community/whisper-large-v3-turbo')
    log.warning(f"未設定 whisper.mlx.model，使用回退值: {model_name}")
```

**配置優先順序**：
```
whisper.mlx.model > whisper.model > 硬編碼預設值
```

## 🐛 問題2：排隊邏輯顯示異常

### 錯誤現象

用戶介面顯示邏輯矛盾：

- **目前排隊人數**：0 人
- **您的排隊位置**：1
- **預計等待**：0 分鐘

**邏輯矛盾**：如果是第1位且不需等待，應該立即開始處理，不應顯示「排隊位置：1」

### 根本原因分析

`backend/services/queue_manager.py` 的 `get_next_task()` 方法：

```python
# 修復前
if task:
    self._processing.add(task_id)
    task.status = TaskStatus.PENDING
    task.queue_position = None  # ✅ 有清除
    # ❌ estimated_wait_seconds 未清除
    task.started_at = datetime.now()
```

**問題**：
- ✅ `queue_position` 被正確清除
- ❌ `estimated_wait_seconds` **未被清除**，仍保留舊值（可能是 0 或其他值）

### 修復方案

```python
# 修復後
if task:
    self._processing.add(task_id)
    task.status = TaskStatus.PENDING
    task.queue_position = None              # ✅ 清除排隊位置
    task.estimated_wait_seconds = 0         # ✅ 新增：清除等待時間
    task.started_at = datetime.now()
```
