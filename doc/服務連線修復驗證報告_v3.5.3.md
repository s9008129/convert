1. **Docker 容器殘留**

   - 狀態: Exited (0) 24 minutes ago

2. **Native 服務程序終止**
   - PID 檔案: `.server.pid` 存在
   - PID 值: 89663
   - 程序狀態: 不存在
   - 埠號: 未被監聽

3. **服務無法訪問**
   - 健康檢查: 失敗
   - API 端點: 無回應
   - WebSocket: 無法連接
