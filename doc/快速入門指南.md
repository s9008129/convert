# MeetingScribe v2.1 快速入門指南

## 🎯 簡介

MeetingScribe 是一個將會議錄音轉換為結構化會議記錄的工具，支援：
- 🔒 **本地模式**：完全離線處理，適合機敏資料
- ☁️ **雲端模式**：使用 Gemini API，高品質摘要

## 🚀 快速部署（Windows 11 + RTX 4090）

### 前置需求

1. **Docker Desktop** 已安裝並運行
2. **Ollama** 已安裝並下載 Gemma3:12B 模型
3. **NVIDIA 驅動** 已安裝（CUDA 支援）

### 步驟 1：建構 Docker 映像

```powershell
cd scripts
.\deploy.ps1 build
```

> ⚠️ 首次建構約需 10-30 分鐘，會下載 Whisper large-v3 模型

### 步驟 2：啟動服務

```powershell
.\deploy.ps1 up
```

### 步驟 3：開啟瀏覽器

訪問 http://localhost:9527

## 📋 使用說明

### 選擇處理模式

- **方案 A（本地模式）**：資料不外傳，適合政府、醫療、商業機密
- **方案 B（雲端模式）**：需設定 Gemini API Key，摘要品質較高

### 上傳檔案

1. 選擇處理模式
2. （選填）輸入自訂 Prompt
3. 拖放或選擇音訊/視訊檔案
4. 等待處理完成
5. 下載 Markdown 結果

## 🔧 管理工具

### 設定 Gemini API Key（雲端模式）

```powershell
.\setup-api-key.ps1
```

### 重啟服務

```powershell
.\restart-service.ps1
```

### 健康檢查

```powershell
.\health-check.ps1
```

## ⚙️ 配置說明

所有設定都在 `.env` 檔案中（複製自 `.env.example`）：

| 設定 | 說明 | 預設值 |
|------|------|--------|
| MAX_FILE_SIZE_MB | 單檔大小上限 | 100 |
| ENABLE_BATCH_UPLOAD | 批次上傳 | false |
| MAX_CONCURRENT_TASKS | 同時處理數 | 1 |
| QUEUE_MAX_SIZE | 排隊上限 | 50 |

## 🆘 常見問題

### Q: 服務無法啟動？
```powershell
docker compose logs  # 查看錯誤訊息
.\health-check.ps1   # 檢查系統狀態
```

### Q: GPU 沒有被使用？
- 確認 NVIDIA 驅動已安裝
- 確認 Docker Desktop 已啟用 GPU 支援
- 系統會自動偵測，若 GPU 不可用會降級到 CPU

### Q: 雲端模式不可用？
- 執行 `.\setup-api-key.ps1` 設定 API Key
- 重啟服務：`.\restart-service.ps1`

# Changelog

All notable changes to MeetingScribe will be documented in this file.

## [2.1.0] - 2025-11-29

### Added
- 🐳 **Docker 跨平台部署支援** - 一包帶走，直接部署
- 🔒 **雙模式處理系統**
  - 本地模式：Ollama + Gemma3:12B（資料不外傳）
  - 雲端模式：Gemini API（高品質摘要）
- 📝 **User Prompt 自訂功能** - 使用者可自訂會議記錄格式
- 📊 **智能排隊系統** - FIFO 公平排隊，前端即時顯示
- 🎛️ **自動裝置偵測** - CUDA/MPS/CPU 智能選擇與降級
- 🛡️ **資源隔離設計** - 不影響 Docker 中其他服務
- 🔧 **友善管理腳本**
  - `setup-api-key.ps1` - API Key 設定工具
  - `restart-service.ps1` - 安全重啟服務
  - `health-check.ps1` - 系統健康檢查

### Changed
- 🏗️ **架構重構** - 採用模組化設計
- 🎨 **全新前端介面** - Apple 風格簡約設計
- ⚙️ **參數化配置** - 所有設定可透過環境變數調整

### Security
- 🔐 **API Key 保護** - 使用 Pydantic SecretStr 處理敏感資料
- 🔒 **Hash 演算法升級** - 從 MD5 改為 SHA256
- 🛡️ **輸入驗證強化** - 檔案大小、格式嚴格驗證

### Fixed
- 修正 WebSocket 連線穩定性問題
- 改善大檔案上傳的記憶體使用

## [1.0.0] - 2025-11-01

### Added
- 初始版本發布
- Whisper 語音轉文字功能
- 基本的會議摘要生成
