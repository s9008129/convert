## 二、更正 2：`cov_missing_number=0` 與清單 `number 4/4` 都是**被高估**的

- 產品側（P4-A 數字對帳器）：`600` 被判「已涵蓋」是**子字串假命中**（紀錄只有 `13,600`）；
  `15` 的命中來自紀錄自己的清單編號（`15.`）。逐字稿確有「發 600塊」「少了 15%」，最終 md／docx 兩者**皆 0 命中**
  （`grep -c '600'`＝1 且僅在 `13,600` 內；`grep -c '15%'`＝0）。
  → 真缺口被漏檢，補強因此沒去補。
- 量尺側（釘版清單 `coverage-1.0.0`）：`F024`（每人發 600 元禮券）以 probe 群組 `['600','便當']` 在 `13,600` 內命中 → 判 covered；
  `F010`（委任 40%→25%、約 15% 升稅務員）以探針群組 `['委任','40','25']` 命中，但紀錄完全沒有 `15%` → 亦為形式命中。
  → **`number 4/4＝1.0` 僅形式達成**；以人工校正估算 `coverage_all` 約 0.7612（`[INFERRED]`，非量尺輸出）。
- 依 plan §9.3 F1①，P4-A 驗收**一律使用釘版量尺且不得回溯套用新尺** → 本更正**不修改任何量尺輸出**，
  僅如實標註其鑑別力限制（屬 P4-G 範圍）。
