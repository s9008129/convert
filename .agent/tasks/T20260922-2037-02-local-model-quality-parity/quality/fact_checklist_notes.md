# 0903-科務會議 事實清單（ground truth）作者筆記

對應檔案：`data/cache/staging/quality/fact_checklist.json`
事實總數：67 條（core 28 條、supporting 39 條）
來源逐字稿：`data/cache/e2e/p2-gemma31b-fix-01/backend_data/outputs/0903-科務會議_ac1edcec_逐字稿.txt`（第二份副本只用來抽查時間戳；兩份前 5 段的段落時間一致）

## 1) core / supporting 怎麼定義

- **core**：一份「可用的會議紀錄」一定會寫出來的東西。包含：關鍵決定（組織改名、業務移撥、搬遷、內稽）、關鍵數字（40% → 25%、800 元 × 17 人 = 13600 元、10 月 14 日）、關鍵待辦（重新列印土地卡、下次科會議報告創新）、關鍵單位名稱，以及會直接影響同仁行為的規範（文康活動核銷規則、資安純文字模式、公務車/洗車、選舉期間政治敏感）。core 漏掉 = 這份紀錄算失敗。
- **supporting**：次要背景、討論過程、舉例、單一承辦細節、未定案的討論。漏掉只是紀錄比較薄，不至於不可用。
- 使用方式：對每條 fact，把受測紀錄去掉空白後做確定性子字串比對；`probes` 的**任一組（group）內所有 token 都命中**就算涵蓋。建議同時輸出「core 命中率」與「整體命中率」兩個分數。

## 2) 已知限制（請務必先讀）

1. **ASR 錯字是最大風險**：逐字稿錯字/同音字很多，若受測紀錄「寫對了」但 probes 沒列到那個寫法，會被誤判成漏掉（偽陰性）。已盡量放變體，但無法窮盡。已知對照：
   - 校費稅科 / 消耗稅科 → **消費稅科**；排香味稅科亦疑為同一科
   - 雞茶股、雞查股 → **稽徵股**；增收股 → **徵收股**
   - 火幣、LB → **臉書**；社料工程 → **社交工程**
   - 餐琴 / 猜庭 / 猜勤 / 拆請 → **差勤**；照時報 → **照實報**；福報 → **浮報**
   - 預佈缺 → **預估缺**；煙 / 菸 混用；裏 / 裡 混用
   - 煙酒離社管科、研究稅管科 → **菸酒及稅務管理科**；工產科有時被聽成工廠科
   - 新聞學校處 → **新聞行銷處**；土地稅客 → **土地稅科**（的空間）
2. **只量「有沒有提到」，不量「寫得對不對」**：如果紀錄寫錯內容但含關鍵詞（例：把 13600 寫成別的用途），仍會被計為涵蓋。正確性/忠實度需要另一把尺。
3. **人名量不到**：逐字稿的發言者只有編號（發言者1–8），出現的人名幾乎都是音譯失真（佩魯科長、博語、美聯、秀正、新化、阿嬌等），無法建立可查核的人名事實。因此本清單只用「單位 / 職稱 / 科別」；人名維度的漏失（漏寫某某人）測不出來。
4. **段落時間戳是系統分段**，且 diarization 有把同一句話切成兩個發言者的情況；`evidence` 裡的「…」代表原文被切段（時間戳/講者標記插入）而非省略內容。
5. 部分事實的「正確寫法」本身就是推測（例如稽徵股、徵收股、消費稅科、預估缺、差勤）。推測只用在 statement 的可讀性與 probes 變體，`evidence` 一律保留原文錯字。

## 3) 刻意不收（噪音或無法判定）的段落

- `[00:00:00]` 開場「管他那個大主任…解除列鬼來」：純 ASR 噪音。
- `[00:05:45]`「同時配合做那個地震」：語意不完整，無法判定是什麼配合事項。
- `[00:08:15]`「6000 的 00」「解決六個」：數字沒有上下文，來歷不明。
- `[00:10:06]`「去年四十放嬌」、`[00:17:36-00:18:09]` 禮券「買 1000 送 100」「全局十幾萬量才有優惠」：語意破碎，無法還原成事實。
- `[00:13:37]` 點心「咳嗽（疑為可頌）夾東西」：不確定品項，只收「點心」層級（F029）。
- `[00:19:08-00:19:49]` 人事室報告（「李飛」「補一層」「姐妹」）：完全無法判定內容。
- `[00:23:00-00:24:07]` 股長人名「博語」「美聯」、`[00:19:31]`「阿嬌姐」「秀正」「新化」：只有音似、身分不明，不收。
- `[00:25:23-00:26:47]`「市場」權限與「瀋圓圓」相關段落：主詞、事件都無法還原；只保留「索取資料要提供」（F043）。
- `[00:31:34]`「全工會/全工櫃拿第二」：對象（全國？全縣？什麼比賽）不明，不收。
- 「91 號早上中午」的日期、「感恩室」的房間名：無法確認正確名稱，不收。
- 淹水當天到場協助的人員（新化夫妻、秀正）：人名不可靠，不收；只收處置方式（F057）。
- 發言者1–8 是系統分群編號不是姓名，任何以「發言者N」為主詞的敘述不視為會議事實。

## 4) 一句話總結

這份清單的價值在於「確定性、可重跑、不靠第二個 LLM」；它的代價是（a）ASR 變體可能造成偽陰性、（b）測不到人名與正確性。建議搭配人工抽查 5–10 條偽陰性候選，再回頭補 probes。
